# 인챈트 인 차트 (Enchant In Chart)

꼬마 마녀 캐시가 테라리움 속 작은 생물들을 몰래 마법으로 도와주는 퍼즐 게임 프로토타입입니다.
5×5 칸 위의 블록에서 '워드'를 가져와 다른 블록에 붙여 세상을 바꿉니다.

## 실행

`web/index.html` 을 브라우저로 열면 됩니다. 빌드 과정은 없습니다.

글꼴·이미지를 불러오지 못하는 브라우저가 있으면 로컬 서버로 여세요.

```bash
python -m http.server 8123 --directory web
```

그다음 `http://localhost:8123` 에 접속합니다.

## 폴더

| 폴더 | 내용 |
|---|---|
| `web/` | 웹빌드 (HTML/CSS/JS, 이미지, LINE Seed 글꼴) |
| `web/js/stages.js` | 스테이지·워드 데이터 |
| `web/js/engine.js` | 규칙 엔진 |
| `web/js/game.js` | 화면·입력·튜토리얼 |
| `web/js/i18n.js` | 한국어·영어·일본어 텍스트 |
| `기획서/` | 기획서, 1스테이지 텍스트, 추가 이미지 리소스 목록 |
| `web-assets-*`, `mobile-ui-assets/`, `ui-key-visuals-mobile/` | 원본 이미지 리소스 |

## 현재 범위

- 타이틀 → 스테이지 선택 → 스토리 컷 → 1스테이지 「첫 번째 불」 → 클리어 결과
- 2·3스테이지는 준비 중
- 리소스가 없는 화면은 기존 이미지와 CSS로 임시 구성 (`기획서/추가_이미지_리소스_목록.md` 참고)
