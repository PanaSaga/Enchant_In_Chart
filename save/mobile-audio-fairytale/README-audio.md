# 오디오 교체팩

ZIP의 assets/audio/를 웹의 같은 경로에 합칩니다. 메뉴곡 greenhouse는 기존 파일입니다. frosted-grid는 78 BPM 3/4박자의 오르골, story-glow는 92 BPM 4/4박자의 피아노와 가벼운 현악입니다. 두 곡은 정해진 마디, 마지막 화음과 잔향을 갖춘 완결형입니다.

탭에는 점토, 선택·성장에는 말랑한 튕김, 대사 넘기기·복제에는 물방울, 마법·보상에는 맑은 종, 이동·분리에는 점토 문지름을 사용합니다. BGM은 OGG·MP3, 효과음은 WAV입니다. 기존 파일명을 유지했습니다.
