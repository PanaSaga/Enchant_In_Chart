## 1. 컨셉 기획서

### 1.1 한 줄 컨셉
**꼬마 마녀가 교수님 몰래 친 작은 사고. 그런데 일이 너무 커져 버렸다?**

연구 과제로 기르던 테라리움 속 작은 생물 '스프라이트'들을 몰래 마법으로 도와주다가, 어느새 그들의 **'신'** 이 되어 버린 꼬마 마녀의 이야기. 스프라이트들은 불을 발견한 순간부터 현대 문명에 이르기까지, 마녀의 손길을 신화와 전설로 기억하게 된다.

### 1.2 제목
**Enchant In Chart** — 칸판(Chart) 위에서 마법을 건다(Enchant).
5×5 그리드 위의 블록에 키워드를 붙여 세상을 바꾸는 게임이라는 뜻이다.

### 1.3 타겟층
- 아기자기하고 귀여운 이야기를 좋아하는 유저
- 시간 압박 없는 가벼운 퍼즐을 좋아하는 유저

### 1.4 레퍼런스

| 구분 | 레퍼런스 | 참고 포인트 |
|---|---|---|
| 인게임 | The Case of the Golden Idol 시리즈 | 장면을 조사해 단서를 모으고 맞춰 넣는 구조 |
| 인게임 | Patch me if you can | 사물의 상태를 바꿔 문제 해결 |
| 인게임 | Baba Is You | 그리드 블록, 속성을 옮겨 규칙을 바꾸는 발상 |
| 아웃게임 | 레이튼 교수 시리즈 | 힌트 코인, 챕터 진행, 이야기와 퍼즐의 결합 |
| 비주얼 | 해리포터 | 마법학교 연구실, 클래식한 마법 소품 |
| 비주얼 | HER TREES : PUZZLE DREAM | 부드러운 파스텔 색감, 몽환적인 퍼즐 화면 |
| 비주얼 | 숲속의 작은 마녀 | 꼬마 마녀의 아기자기한 생활감 |

### 1.5 핵심 재미
1. **키워드 인챈트** — 블록에서 얻은 키워드를 다른 블록에 붙인다. "열이 자란다", "모닥불이 이동한다" 같은 엉뚱한 조합이 정답이 된다.
2. **신화와 전설 오마주** — 스테이지마다 인류 역사의 한 시대와 그 시대의 신화·전설을 귀엽게 비튼다.
3. **커져 가는 사고** — 작은 도움이 문명을 만들고, 마녀는 원치 않게 신이 된다.

## 2. 핵심 메카닉스

### 2.1 게임 설명

#### 2.1.1 코어 루프

```
찾는다(파인드) ─▶ 맞춘다(인챈트) ─▶ 전환한다(상태 변화) ─▶ 목표 달성
      ▲                                              │
      └──────────── 새 블록·키워드 등장 ◀─────────────┘
```

**아웃게임:** 클리어 → 별·코인 획득 → 힌트·별 구매 → 다음 챕터 해금

#### 2.1.2 게임 진행
1. 스테이지 시작 시 목표를 확인한다.
2. **파인드**로 블록을 조사해 정보를 보고, 가져올 수 있는 키워드를 얻는다.
3. 얻은 키워드는 그리드 오른쪽의 **키워드 창**에 소모 개수와 함께 모인다.
4. **인챈트**로 키워드를 다른 블록에 붙여 특성을 바꾼다.
5. **무브**와 **자란다**로 블록을 옮기거나 키워서 블록끼리 만나게 한다.
6. 블록의 상태가 바뀌며 사건이 진행되고, 목표를 이루면 클리어한다.

#### 2.1.3 그리드와 블록

**그리드**
- 5×5 칸. 행 **A~E**(위→아래), 열 **1~5**(왼쪽→오른쪽)
- 한 칸에는 블록 하나만 놓인다. 블록은 다른 블록이 있는 칸으로 이동하거나 자랄 수 없다. 따라서 한 번 생긴 블록(예: 열)은 다른 블록에 밀려 사라지지 않는다. (일부 특수 블록 제외)
- 결과 판정(화상, 화재, 조합 등)은 **드래그를 놓는 순간** 일어난다. 오답이면 연출 후 자동 복구된다.
- **주변 1칸** = 상하좌우와 대각선을 포함한 8칸
- **닿는다** = 블록의 변이 맞붙어 있다

**블록**
- 블록은 가로×세로 크기의 직사각형이다. (예: 나무 1×2, 수증기 1×1)
- 블록마다 **분류**, **상태**, **키워드**, **인챈트 가능 여부**를 가진다.

| 분류 | 설명 | 예시 |
|---|---|---|
| 마법 | 마법 장치. 자랄 수 없다 | 온도 조절 마법진 |
| 사물 | 일반 물체 | 나무, 수증기, 나뭇가지 |
| 인물 | 테라리움 속 생물 | 엄마, 딸 |
| 상태 | 주변에 영향을 주는 현상 | 열 |

#### 2.1.4 키워드

#게임 안에서 키워드는 **'워드'** 라고 부른다. (예: "'워드'가 있는 건 조종할 수 있어!")

#### 키워드 규칙
- **획득 가능 여부:** 가져올 수 있는 키워드와 정보로만 보이는 키워드가 있다. 가져온 키워드는 **원래 블록에서 빠진다.**
- **소모 개수:** 키워드는 정해진 횟수만큼 인챈트할 수 있다. 횟수를 다 쓰면 카드가 사라진다.
- **부여 대상:** 인챈트 가능한 블록에만 붙일 수 있으며, 키워드별 조건도 따른다.

##### 키워드 색상
키워드는 동작 종류에 따라 고유 색을 가진다.
- 같은 색 = 같은 동작
- 한 블록에는 **색마다 키워드 1개**만 붙는다.
- 같은 색 키워드를 붙이면 기존 키워드와 **교체**되고, 밀려난 키워드는 사라진다. (되돌리기로는 복구된다)

| 색 | 동작 | 키워드 |
|---|---|---|
| 🟡 노랑 | 드래그로 쓰는 동작 | 이동, 자란다※, 자란다↕, 자란다↔, 자란다✚ |
| 🔵 파랑 | 터치로 쓰는 동작 | 분리 |
| 🔴 빨강 | 주변에 자동으로 퍼지는 효과 | 열 전달, 연소 부여, 모닥불 |
| 🟢 초록 | 주변 효과를 막는 효과 | 차단 |
| ⚪ 회색 | 상태 (교체 규칙 없음) | 위험, 추위, 따뜻함, 더움 |

##### 자란다 4종
모두 노란색이라 서로 교체된다. **↕와 ↔를 바꿔 끼워 가며 블록을 키우는 것**이 핵심 플레이다. 마법 블록에는 붙일 수 없다.

- 드래그한 거리만큼 자라고, 반대로 드래그하면 줄어든다.
- 블록마다 **기본 크기**가 있고, 기본 크기 미만으로는 줄어들지 않는다. (예: 수증기 1×1, 나무 1×2)

| 키워드 | 자라는 방식 |
|---|---|
| 자란다↕ | 세로로만 자란다 |
| 자란다↔ | 가로로만 자란다 |
| 자란다✚ | 가로세로 비율을 유지한 채 커진다 (예: 1×1 → 2×2, 1×2 → 2×4) |
| 자란다※ | 당기는 길을 따라 꺾이며 자란다 |

예) 1×1 열에 ↔를 붙여 4×1로 키운 뒤, ↕로 교체해 4×2로 키운다.

##### 키워드 사전

| 키워드 | 색 | 효과 |
|---|---|---|
| 이동 | 🟡 | 무브로 옮길 수 있다 |
| 자란다↕ / ↔ / ✚ / ※ | 🟡 | 위 표 참고 |
| 분리 | 🔵 | 기본 2칸 이상 사물에만 적용. 블록을 클릭하면 블록 안 칸의 꼭짓점을 잇는 가로·세로 절단선이 나타나고, 그 선을 따라 드래그하면 그 자리에서 잘린다. 뿌리 위쪽 조각은 나뭇가지가 된다. 뿌리 쪽 조각은 1×2 이상이면 자란다를 유지하고, 1×1이 되면 자란다를 잃는다. 1회 사용 후 사라진다 |
| 열 전달 | 🔴 | 주변 1칸의 빈칸에 '열' 블록을 만든다. 수증기가 사라진 칸에도 생긴다 |
| 연소 부여 | 🔴 | 닿은 대상에 '연소' 상태를 준다 |
| 모닥불 | 🔴 | 주변 1칸 대상에게 '따뜻함'을 부여한다. '추위'가 있는 대상은 '추위'가 제거되고, 이미 '따뜻함'이 있는 대상은 '더움'으로 바뀐다 |
| 차단 | 🟢 | 주변으로 전달되는 효과를 막는다 |
| 위험 | ⚪ | 세로 2칸 이상 나무의 상태. 열이 닿으면 화재가 난다 |
| 추위 | ⚪ | 이동을 방해한다 |
| 따뜻함 | ⚪ | 몸이 녹은 상태 |
| 더움 | ⚪ | 따뜻함이 겹쳐 너무 더운 상태 |

##### 조합 규칙

| 조합 | 결과 |
|---|---|
| 나뭇가지 + 연소 | 모닥불 |
| 나무(세로 2칸 이상) + 열 | 화재 (오답). 분리 후 세로 2칸 이상으로 남은 조각도 해당 |
| 인물 + 열 | 화상 (오답) |

#### 2.1.5 하트 · 별 · 되돌리기

| 항목 | 규칙 |
|---|---|
| 제한시간 | 없음 |
| 하트 | 5개로 시작. 오답마다 1개 감소 |
| 별 | 하트 2개를 잃을 때마다 1개 감소 (최소 1개) |
| 하트 0개 | 클리어 가능 |
| 힌트 사용 | 별에 영향 없음 |

| 실수 횟수 | 0~1 | 2~3 | 4 이상 |
|---|---|---|---|
| 획득 별 | ★★★ | ★★ | ★ |

**오답과 불가능한 행동**
- **오답 (하트 −1):** 실행은 됐지만 결과가 나쁜 행동. 실패 연출 후 직전 상태로 자동 복구되며, 쓴 소모 개수는 돌려준다.
- **불가능한 행동 (하트 감소 없음):** 인챈트 불가 블록에 드래그, 획득 불가 키워드 가져오기, 이동 불가 블록 당기기. 키워드가 튕겨 나오는 연출만 보여 준다.

**되돌리기**
- 직전 행동 1회를 취소하고, 그 행동에 쓴 소모 개수를 돌려준다.
- 잃은 하트는 회복되지 않는다.
- 소모 개수가 부족해 더 풀 수 없는 상태가 되면, 캐시가 "어라, 다시 해 볼까?"라고 말하며 되돌리기·재시작 버튼을 강조한다.

#### 2.1.6 아웃게임

| 요소 | 획득 | 사용처 |
|---|---|---|
| 별 | 클리어 시 1~3개 | 일정 개수 이상이면 다음 챕터 해금 |
| 코인 | 클리어 보상, 출석, 광고 보상, 인앱 구매 | 힌트 구매, 별 구매 |

- **클리어 보상:** 코인 30 (별 개수와 무관)
- **챕터 해금:** 챕터 1~5는 3스테이지, 챕터 6은 5스테이지. 다음 챕터는 이전 챕터에서 별 6개 이상 필요
- **별 구매:** 별 3개 미만으로 클리어한 스테이지는 부족한 별을 코인으로 채울 수 있다. 같은 판을 다시 플레이할 필요가 없게 하기 위함이다.
- **힌트 3단계**

| 단계 | 내용 | 비용 |
|---|---|---|
| 1 | 어떤 블록을 볼지 | 코인 10 |
| 2 | 어떤 키워드를 쓸지 | 코인 20 |
| 3 | 다음 행동 표시 | 코인 40 |

### 2.2 조작법

모바일 기준 게임이므로 **모든 동작은 클릭과 드래그만으로** 수행한다. (더블 탭, 길게 누르기, 멀티 터치 없음)

| 마법 · 동작 | 조작 | 효과 |
|---|---|---|
| **파인드** | 블록 클릭 | 블록 정보를 보고, 가져올 수 있는 키워드를 키워드 창에 담는다 (원래 블록에서 빠짐) |
| **인챈트** | 키워드 카드를 블록으로 드래그 | 키워드를 블록에 부여한다 |
| **무브** | 블록을 누른 채 드래그 | 블록에 붙은 노란 키워드에 따라 **이동**하거나 **자란다** |
| **분리** | '분리'가 있는 블록 클릭 → 칸 꼭짓점을 잇는 가로·세로 절단선 표시 → 원하는 선을 따라 드래그 | 그 선에서 블록이 잘린다 |
| 되돌리기 | 버튼 클릭 | 직전 행동 1회 취소 |
| 힌트 | 버튼 클릭 | 코인으로 힌트 열람 |

## 3. 시놉시스

### 3.1 이야기

마법학교 연구실의 견습 마녀 **캐시**는 연구 과제로 만든 작은 테라리움을 관찰하며 일지를 쓰고 있다. 유리병 속에서 생물이 태어나고 진화하는 모습을 지켜보던 캐시는 어느새 그들에게 정이 든다.

어느 날 냉방 마법 오류로 연구실 온도가 떨어지고, 테라리움 속 생물들이 추위에 떨기 시작한다. 이대로 생물들이 죽으면 연구는 끝장이다. 그렇다고 교수님께 말했다간 혼날 것 같은데….

캐시는 몰래 테라리움 안에 작은 마법을 걸어 생물들을 지키기로 한다. 그 작은 마법이 불이 되고, 비가 되고, 기적이 되어 생물들의 문명을 키워 간다. 생물들은 하늘 너머의 존재를 신으로 섬기기 시작하고, 캐시의 사고는 점점 커져만 간다.

#### 스토리 진행 (20스테이지)

**1~15스테이지:** 인류가 불을 발견한 때부터 현대의 컴퓨터와 AI까지, 인류의 진화와 발전 단계를 따라가며 각 단계와 관련된 세계 신화·전설을 오마주한다.
**16~20스테이지:** 캐시가 친구 데비와 함께 망가진 세계를 되돌린다.

| 챕터 | 스테이지 | 시대 | 인류의 발전 | 오마주 | 사건 |
|---|---|---|---|---|---|
| **1. 작은 도움** | 1 | 선사 | 불 | 프로메테우스 (그리스) | 첫 번째 불 |
| | 2 | 신석기 | 농경 | 데메테르 (그리스) | 메마른 밭에 내리는 비 |

| | 5 | 고대 문명 | 도시와 건축 | 바벨탑 (메소포타미아) | 하늘에 닿는 탑 |

**관계 변화**
- **챕터 1~2:** 흥미를 느끼고 가볍게 도와주다가, 스프라이트들에게 '신'으로 알려진다.
- **챕터 3:** 모든 스프라이트가 캐시를 신으로 추앙한다.
- **챕터 4:** 스프라이트들이 신의 은혜만 바라고, 퍼즐이 더 어려워진다.
- **챕터 5:** 테라리움의 문명이 손쓸 수 없이 커지고, 친구 데비에게 사실을 들켜 혼이 난다.
- **챕터 6:** 캐시와 데비가 함께 테라리움의 시간을 거꾸로 되감는다. 스테이지마다 앞서 붙였던 키워드를 떼어 내며 시대를 하나씩 되돌린다.

**결말 (20스테이지):** 캐시는 지금까지 얻은 키워드를 모두 모아 테라리움 안의 시간을 처음으로 되돌린다. 모든 사고의 시작이었던 온냉방 마법의 오류 자체를 고쳐, 테라리움의 환경을 지켜 낸다.

**테마:** 사랑하는 대상을 돕는 일과, 그들 스스로 살아가게 두는 일 사이의 균형.

#### 아트 방향

**질감과 톤**
- 크레용·색연필로 그린 듯한 거친 손그림 질감. 면은 종이 결이 비치게 칠하고, 선은 부드러운 갈색·초록색
- 따뜻한 파스텔 톤. 크림색 종이, 민트·청록, 연두, 주황을 중심으로 쓴다

**배경**
- 유리 온실(테라리움 연구실). 아치형 유리창 너머 하늘, 창틀을 타고 내려오는 덩굴과 잎, 화분과 보라색 꽃
- 화면 가장자리에 클로버, 작은 들꽃, 책 더미, 유리병 테라리움 같은 소품을 장식으로 배치

**그리드**
- 청록색 판 위에 민트색 체크무늬 칸. 칸 사이 테두리는 짙은 초록
- 블록은 칸을 꽉 채우는 질감 타일
  - 수증기: 하늘색 바탕에 흰 구름 무늬
  - 온도 조절 마법진: 주황 물결무늬
  - 나무: 연두색 잎 덩어리 타일, 아래 칸에 주황색 줄기
  - 스프라이트: 칸 안에 들어가는 캐릭터 일러스트. 추위 상태는 몸을 웅크리고 떨림 선 표시

**캐릭터**
- 캐시: 초승달 장식의 보라색 마녀 모자, 갈색 곱슬머리, 발그레한 볼. 초상화는 크림색 액자 안에 표정만 바뀐다
- 스프라이트: 털옷을 입은 작은 원시인 모습의 엄마와 딸. 갈색 곱슬머리, 동그란 얼굴

**UI**
- 크림색 종이 패널에 초록 테두리, 둥근 모서리 (9-slice)
- 대사창은 캐시 초상화에서 나오는 말풍선
- 하트는 빨강, 코인은 금색 동전, 별은 주황빛 노랑
- 키워드 카드는 둥근 알약 모양. 선택·획득한 카드는 주황, 빈 칸은 민트
- 힌트(전구)·되돌리기(주황 화살표) 버튼은 크림색 정사각 버튼
- 글꼴은 둥글고 굵은 손글씨풍 한글

| 2 | 파인드 | 수증기(B3) 클릭 → 자란다↔ 가져오기 | 키워드가 빠진 수증기가 흩어지고, B3에 **열**이 생긴다 |
| 3 | 파인드 | 열 클릭 | '연소 부여' 확인 |
| 4 | 파인드 | 나무 클릭 → 자란다↕ 가져오기 | 상태 '위험' 확인 |
| 5 | 파인드 | 엄마 또는 딸 클릭 → 이동 가져오기 | 상태 '추위' 확인 |
| 6 | 분리 | 나무 클릭 → D1과 E1 사이의 가로 절단선을 따라 드래그 | D1이 떨어져 **나뭇가지**가 된다. 두 조각 모두 1칸이 되어 위험 해제 |
| 7 | 인챈트 | 자란다↔를 B3의 열에 드래그 | 열이 가로로 자랄 수 있다 |
| 8 | 무브 | 열을 왼쪽으로 드래그해 B1까지 키운다 | 열 3×1 (B1~B3) |
| 9 | 인챈트 | 자란다↕를 같은 열에 드래그 | ↔가 ↕로 교체된다 |
| 10 | 무브 | 열을 아래로 드래그해 C행까지 키운다 | 열 3×2 (B1~C3). C1이 나뭇가지(D1)에 닿아 **모닥불**이 된다 |
| 11 | 인챈트 | 이동을 모닥불에 드래그 | 모닥불을 옮길 수 있다 |
| 12 | 무브 | 모닥불을 D3으로 옮긴다 | 엄마(D4·E4)와 딸(E3)이 모두 주변 1칸에 들어와 **따뜻함** → 클리어 |

- ↕를 먼저 쓰고 ↔를 나중에 써도 풀린다. (B3→C3, 그다음 C1까지)
- 모녀를 함께 데울 수 있는 칸은 D3 하나뿐이다.
- 나무가 1×3 이상으로 자라 있으면, 자르는 위치에 따라 세로 2칸 이상 조각이 남아 '위험'을 유지한다. 열이 그 조각에 닿지 않게 키워야 한다.
- 키워드는 넉넉하게 준다. (자란다↔ 최대 5개, 이동 최대 2개)

#### 오답

| 행동 | 결과 | 하트 |
|---|---|---|
| 4열의 수증기(B4)를 없애 생긴 열을 C행까지 키움 | C4가 엄마(D4)에 닿아 화상 → 자동 복구 | −1 |
| 분리하지 않은 나무, 또는 세로 2칸 이상 남은 조각에 열이 닿음 | 화재 → 자동 복구 | −1 |
| 인챈트 불가 블록에 키워드를 드래그 | 튕겨 냄 | 0 |
| 가져올 수 없는 키워드를 가져오려 함 | 반응 없음 | 0 |

### B.2 일정

| 일차 | 목표 | 작업 |
|---|---|---|
| Day 1 | 코어 엔진 + 1스테이지 | 그리드, 블록·키워드 데이터, 파인드·인챈트·무브, 분리·자란다, 열 전달·차단·연소, 조합 규칙. 1스테이지 정답 루트 동작 |
| Day 2 | 시스템 + 2·3스테이지 | 하트·별·되돌리기, 오답 판정, 튜토리얼 안내, 2·3스테이지 확정 및 구현, 힌트·코인, 결과·스테이지 선택 화면 |
| Day 3 | 완성도 | 스토리 컷, 인챈트·상태 이펙트, 효과음, 클릭·드래그 입력 통일(마우스·터치 공용), 정사각형 화면 레이아웃, 플레이 테스트, 버그 수정 |

### B.3 기술 메모
- 스테이지는 **JSON 데이터**로 정의하고, 하나의 엔진이 읽어 실행한다.

| 데이터 | 내용 |
|---|---|
| blocks | id, 분류, 위치·크기 `{x, y, w, h}`, 상태, 키워드, 인챈트 가능 여부 |
| blockKeywords | 키워드별 획득 가능 여부, 소모 개수 |
| keywords | id, 색, 종류(특성/상태), 부여 조건 |
| rules | 조합 결과 (예: 나뭇가지 + 연소 → 모닥불) |
| goal | 클리어 조건 (예: 엄마·딸 = 따뜻함) |

- 블록 키워드는 `{색: 키워드}` 맵으로 저장하면 "색마다 1개, 같은 색은 교체" 규칙이 자동으로 지켜진다.
- 자란다↕는 h, ↔는 w, ✚는 비율을 유지해 w·h를 함께 늘린다. ※만 칸 목록(경로)으로 저장한다.
- 행동마다 그리드 스냅샷을 저장해 되돌리기와 오답 자동 복구에 함께 쓴다.
- 매 행동 후 효과를 순서대로 처리한다: 열 전달 → 차단 확인 → 연소 부여 → 조합 → 모닥불 효과 → 목표 확인.
