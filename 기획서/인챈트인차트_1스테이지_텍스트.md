# 인챈트 인 차트 · 1스테이지 텍스트 초안

말하는 사람은 모두 **캐시**예요. 게임 안에서 키워드는 **'워드'** 라고 불러요. 대사창에 한 줄씩 띄우고, 클릭하면 다음 줄로 넘어가요.

## 3. 튜토리얼

조건이 맞으면 대사를 띄우고, [가이드]가 있으면 해당 블록에 손가락 가이드를 표시해요.

| 단계 | 띄우는 조건 | 대사 | 표정 |
|---|---|---|---|
| 1 | 시작 대사 다음 | 온도 조절 마법진을 고치긴 했는데, 왜 테라리움 안의 온도가 올라가지 않지? | 당황 |
| | | 수증기 때문에 열이 흙까지 닿지 않잖아?! | 놀람 |
| | | 수증기를 치울 수 있을까? 한 번 살펴봐야겠어. [가이드: 수증기] | 기본 |
| 2 | 수증기 클릭 후 | 아, '워드'가 붙어 있구나. '워드'가 있는 건 조종할 수 있어! 한 번 해 보자. [가이드: 자란다↔ 가져오기] | 기쁨 |
| 3 | 자란다↔를 가져온 후 | 흩어졌다! 이제 열이 닿고 있지만... 이 속도로는 테라리움이 다 데워지기 전에 스프라이트가 얼어 죽을 거야. | 당황 |
| | | 더 빠르게 열을 전달하고 유지할 방법이 없을까? | 기본 |
| | | 다른 사물들을 살펴보자. 다른 '워드'를 이용하면 가능할 거야. | 기본 |
| 4 | 열 클릭 후 | 열에도 '워드'가 있네. 닿는 건 뭐든 태운다고...? | 놀람 |
| | | 그럼... 불을 피울 수 있겠어! 불이면 열을 계속 유지할 수 있잖아! | 기쁨 |
| 5 | 나무 클릭 후 | 나무엔 '위험'이 붙어 있어. 이렇게 큰 나무에 열이 닿으면... 숲이 통째로 타 버릴 거야. | 당황 |
| | | 조금만 떼어 내서 태울 수는 없을까? | 기본 |
| | | '자란다'는 챙겨 두자. 분명 쓸 데가 있을 거야. [가이드: 자란다↕ 가져오기] | 기본 |
| 6 | 엄마 또는 딸 클릭 후 | 추위 때문에 몸이 굳어서 움직이질 못하네... | 당황 |
| | | '이동' 워드가 있어. 이건 유용하겠는걸? 잠깐 빌려갈게. [가이드: 이동 가져오기] | 기쁨 |
| 7 | 이동을 가져온 후 | 나무에 '분리'가 있었지? 위쪽만 잘라 내면 위험하지 않을 거야. [가이드: 나무] | 기본 |
| | 나무 클릭해 절단선이 나온 후 | 선을 따라서... 조심조심, 쭈욱! [가이드: D1–E1 절단선] | 기본 |
| | 분리 후 | 됐다! 이 정도 나뭇가지면 불쏘시개로 딱이야. | 기쁨 |
| 8 | 위 대사 다음 | 이제 열을 나뭇가지까지 보내야 해. 열에 '자란다'를 붙이면... 뻗어 나가지 않을까? [가이드: 자란다↔ → 열] | 기본 |
| | 열에 자란다↔를 붙인 후 | 좋아, 옆으로 쭉 늘려 보자! | 기쁨 |
| 9 | 열이 B1까지 닿은 후 | 여기서 아래로 꺾어야 하는데... 노란 '워드'는 하나만 붙어. ↕로 바꿔 끼우자! [가이드: 자란다↕ → 열] | 기본 |

| 11 | 위 대사 다음 | 근데 모녀랑 너무 멀어... 아까 빌린 '이동', 여기 붙이면 되겠다! [가이드: 이동 → 모닥불] | 기본 |
| 12 | 모닥불에 이동을 붙인 후 | 둘 다 따뜻해지려면... 어디에 두는 게 좋을까? | 기본 |

## 8. 워드 설명창

캐시의 관찰일지 메모처럼 짧게 써요.

| 워드 | 설명 |
|---|---|
| 열 전달 | 주변 한 칸에 열을 내보내. 막히지만 않으면. |
| 연소 부여 | 닿으면 불이 붙어. |
| 차단 | 주변으로 퍼지는 걸 막아. |
| 자란다↔ | 옆으로 늘였다 줄였다. |
| 자란다↕ | 위아래로 늘였다 줄였다. |
| 이동 | 끌어서 옮길 수 있어. |
| 분리 | 선을 따라 한 번 자를 수 있어. |
| 모닥불 | 주변 한 칸을 따뜻하게 해. 너무 오래 쬐면 더워. |
| 위험 | 열이 닿으면 불나. |
| 추위 | 추워서 꼼짝 못 해. |
| 따뜻함 | 몸이 다 녹았어. |
| 더움 | 땀 뻘뻘. 너무 따뜻해. |

## 9. 힌트

진행 상황에 따라 힌트 내용이 바뀌어요.

| 진행 상황 | 1단계 (어디를 볼지) | 2단계 (무엇을 쓸지) | 3단계 (다음 행동) |
|---|---|---|---|
| 열이 아직 없음 | 마법진 주변을 봐. | 수증기한테서 '워드'를 가져와 봐. | B3 수증기를 눌러서 자란다↔를 가져와. |
| 열은 있고 모닥불은 없음 | 열이 나무에 닿아야 해. 근데 나무가 너무 커. | 분리로 나무를 자르고, 열에 자란다↔·↕를 번갈아 붙여. | 나무 위쪽을 자르고, 열을 B1까지 옆으로, 그다음 C행까지 아래로. |
| 모닥불이 생김 | 모닥불이 모녀 곁에 있어야 해. | 모녀한테서 이동을 가져와 모닥불에 붙여. | 모닥불을 D3로 옮겨. |
