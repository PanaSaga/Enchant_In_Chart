# 추가로 필요한 이미지 리소스 목록

웹빌드(`web/`)에서 현재 **임시 처리**(기존 리소스 재활용, CSS, 이모지, SVG)로 때운 부분입니다.
우선순위 ★★★ = 없으면 어색함이 큼 / ★★ = 있으면 완성도 상승 / ★ = 나중에.
규격은 기존 세트(72 DPI, 4의 배수, 투명 PNG)에 맞춘 제안값입니다.

## 5. 클리어 (엔딩 컷 + 결과 화면)

클리어 대사는 "휴우... 다행이다..." 한 줄입니다. 스프라이트들은 아직 마녀를 알아채지 못하므로, 올려다보거나 눈이 마주치는 장면은 넣지 않습니다.

| 우선 | 리소스 | 제안 규격 | 현재 임시 처리 |
|---|---|---|---|
| ★★★ | 엔딩 컷: **모닥불가에 꼭 붙어 앉아 손을 녹이는 모녀** | 812×812 | 없음 (인게임 대사만) |
| ★★ | 엔딩 컷 2: 테라리움을 내려다보며 **안도하는 캐시** | 812×812 | 없음 |
| ★★★ | 결과 **패널 배경**, '클리어!' 타이틀 글자(3개 언어) 또는 리본 | 800×900, 600×160 | objective-frame.png + 글꼴 글자 |
| ★★ | **큰 별** 획득 연출용 (켜짐 / 꺼짐 / 반짝임) | 256×248 (기존 star 재사용 가능) + 반짝임 256×256 | 기존 star.png 확대 |
| ★★ | 버튼: **다음 스테이지 / 다시 하기 / 스테이지 선택 / 별 채우기** | 각 9-slice 또는 아이콘 128×128 | icon-button.png + 글자 |
| ★ | 코인 획득 연출 (동전이 튀는 이펙트) | 256×256 | 숫자만 표시 |
| ★ | 꽃가루·반짝이 배경 장식 | 1024×600 | 없음 |

## 참고: 이미지가 아닌 것

- **효과음·배경음**은 아직 하나도 없습니다. (기획서 Day 3 항목)
- 캐시 초상화 8종 중 인게임에서 쓰는 것은 neutral / worried / surprised / happy / victory 5종입니다. angry · sad · defeat 는 아직 쓰는 곳이 없습니다.
