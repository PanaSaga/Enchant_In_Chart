# 인챈트 인 차트 웹 리소스

확정한 인게임 화면과 1스테이지 「첫 번째 불」에 쓰는 PNG 세트입니다. 각 파일은 72 DPI 메타데이터를 가지며, 가로와 세로 크기는 모두 4의 배수입니다. 웹에서 실제 표시 크기는 CSS로 지정합니다.

| 폴더 | 용도 |
|---|---|
| `tiles/` | 256×256 퍼즐 타일. 엄마와 전체 나무는 256×512입니다. `thermostat`은 태양, `heat`는 옅은 노란빛 물결입니다. `tree-crown`과 `tree-trunk`는 분리·성장 연출에도 사용할 수 있습니다. |
| `keywords/` | 72×72 공통 키워드 배경 5색. 키워드명과 수량은 HTML로 얹습니다. |
| `ui/` | 144×144, 256×256, 512×512 패널·액자·버튼 배경. 말풍선은 몸통과 꼬리가 분리되어 있습니다. |
| `icons/` | 버튼 배경이 분리된 투명 아이콘. `heart-off`와 `star-off`는 같은 실루엣의 무채색 버전입니다. |
| `portraits/` | 배경과 액자가 없는 512×512 캐시 초상화 8종. 가운데 하단을 기준으로 교체합니다. |
| `decor/` | 너비 1600px의 온실 배경, 책, 테라리움, 이끼풀밭. 아래 장식 세 종류에는 투명 배경이 있어 각각 배치할 수 있습니다. |

인물과 소품은 지정된 타일 안에서 비율을 유지하며 가로나 세로 한쪽을 최대로 채웠습니다. 원본과 타일의 종횡비 차이는 투명 영역으로 남습니다.

## 키워드 색

| 파일 | 분류 | 예 |
|---|---|---|
| `yellow.png` | 드래그 동작 | 이동, 자란다 |
| `blue.png` | 터치 동작 | 분리 |
| `red.png` | 자동 확산 효과 | 열 전달, 연소 부여, 모닥불 |
| `green.png` | 주변 효과 차단 | 차단 |
| `gray.png` | 상태 키워드 | 위험, 추위, 따뜻함 |

## 수채·크레파스 재제작

새 색채 원본을 사용했습니다. 올리브 테두리는 central-panel을 기준으로 매끈하게 다듬었습니다. 기존 경로와 9-slice 인셋을 유지합니다. 아이콘의 가로는 256px이며 세로는 실루엣에 맞춥니다.

## 9-slice

`manifest.json`의 `slice`는 원본 픽셀 기준으로 위, 오른쪽, 아래, 왼쪽 순입니다. `portrait-frame` 위에 초상화를 얹고, `speech-body` 옆에는 `speech-tail`을 몸통 테두리와 살짝 겹치게 배치합니다. 아래 예시는 72px 원본의 모서리를 화면에서 원본 크기의 약 ¼로 표시합니다.

```css
.keyword-yellow {
  border: 6px solid transparent;
  border-image: url("./keywords/yellow.png") 21 fill stretch;
}
```

나무는 칸을 채우는 큰 잎 색면을 사용합니다. 체크·수증기 구름·열 물결은 유지했습니다.
캐시 표정 8종은 제공된 마녀 시트에서 분리해 외곽의 들뜬 픽셀을 정리했습니다.

## 최종 세트

마녀 8종은 512×512px 공통 포즈·실루엣을 사용합니다. 반짝이 효과는 공통 캔버스에 추가했습니다.
수증기는 연하늘색 안개 패턴이며, 기존 타일의 색조와 무늬를 유지하면서 명암 차를 줄였습니다.
기본 퍼즐 1안은 tiles/에, 교체용 퍼즐 2안은 alternatives/puzzle-2/tiles/에 있습니다.
9-slice 인셋과 그림의 투명 외곽은 기존 규격을 유지합니다.

마녀 얼굴 변경본은 분홍색 둥근 눈동자, 큰 홍조, 단순한 입을 사용합니다. 코와 안경은 생략했습니다. 기존 512×512px 기준점과 투명 외곽은 그대로입니다.

로즈쿼츠 버전은 밝고 균일한 분홍색 눈동자를 적용했습니다. 승리의 눈 속 별은 유지했고, 머리카락 밖에 드러나는 눈썹은 한쪽만 남겼습니다.

리터칭 버전의 평소 표정은 사용자가 제공한 얼굴을 기준으로 맞췄습니다. 넓게 퍼지는 채색을 사용합니다. 512×512px 기준점과 자산 경로는 이전 세트와 같습니다.

보라색 하이칼라 버전의 평소 표정은 사용자의 리터칭 원본에서 눈썹·눈매·안광을 가져왔습니다. 8종에 같은 보라색 칼라와 노란 장식, 같은 512×512px 기준점을 적용했습니다.

평소 표정의 눈매·속눈썹·안광은 사용자가 리터칭한 얼굴에서 직접 가져왔습니다. 8종의 512×512px 기준점과 보라색 하이칼라의 위치를 맞췄습니다.

콘티 신규 마녀는 보라색 모자와 망토, 모자의 노란 초승달, 흰 꽃잎과 노란 리본을 사용합니다. 눈을 뜬 여섯 표정 모두의 홍채와 별은 사용자 지정 시트를 기준으로 합성했습니다. 평소 표정의 위로 튀어나온 속눈썹은 정리했습니다. 8종 모두 512×512px, 72 DPI와 같은 바깥 실루엣을 사용합니다.

표시한 네 표정의 얼굴 부분만 정리했습니다. 디폴트 표정에는 보라색 옷, 노란 초승달, 흰 꽃잎과 노란 리본이 포함됩니다.
