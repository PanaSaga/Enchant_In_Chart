# 모바일 UI 추가 리소스

이 폴더에는 기존 웹 리소스에 없는 PNG만 들어 있습니다. ZIP 안의 `assets/` 하위 폴더를 프로젝트의 `web/assets/`에 추가할 수 있습니다. 기존 `manifest.json`과 경로가 겹치지 않도록 `mobile-ui-manifest.json`에 새 파일과 재사용 경로를 기록했습니다.

| 화면 | 새 PNG | 기존 리소스 활용 |
|---|---|---|
| 표지 | 한글 로고, 캐시와 테라리움이 함께 있는 삽화, 공통 청록 버튼 | 온실, 이끼풀밭, 언어 선택 칩 |
| 스테이지 선택 | 관찰일지 9-slice, 책갈피·잠금 탭, 비·강 썸네일, 자물쇠 | 1스테이지는 기존 모닥불을 썸네일로 사용합니다. 코인·별·설정·화살표·책·테라리움도 재사용합니다. |
| 힌트 | 살펴보기·키워드·다음 행동 아이콘, 닫기 X, 꽃과 잎 장식, 호박색 칩 | 힌트 전구, 캐시 초상화, 코인, 크림 대화상자와 버튼, 기존 플레이 화면 |
| 설정 | 일지 아이콘, 공통 청록 버튼과 호박색 칩 | 해 모양 설정과 되돌리기 아이콘, 크림 대화상자와 언어 칩, 기존 플레이 화면 |
| 클리어 | 축하 삽화와 꽃 장식, 공통 청록 버튼 | 별, 코인, 크림 결과 패널, 온실, 이끼풀밭 |

패널·버튼의 9-slice 인셋은 원본 픽셀 기준 위·오른쪽·아래·왼쪽 순서입니다. 관찰일지의 책갈피와 가죽 잠금 탭은 별도 이미지로 배치합니다. 버튼·메뉴의 문구와 숫자는 기존 웹 폰트와 다국어 문자열을 사용합니다. 표지의 한글 로고만 이미지로 제공합니다.

```css
.mobile-journal {
  border: 0 solid transparent;
  border-image: url("../assets/ui/mobile/journal-panel.png") 92 fill / 22px;
}
.mobile-primary {
  border: 0 solid transparent;
  border-image: url("../assets/ui/mobile/action-primary.png") 46 fill / 19px;
}
```
